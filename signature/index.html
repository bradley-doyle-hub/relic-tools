Email signatures

Pick your name, check the details, then click Copy signature and paste it into your email settings. Steps for Gmail, Apple Mail and Outlook are below. Takes about two minutes.

Install it

Gmail

  1. Click Copy signature.
  2. Gmail › Settings (gear) › See all settings.
  3. General › Signature › Create new, name it.
  4. Paste into the box, then Save changes at the bottom.

Apple Mail

  1. Click Copy signature.
  2. Mail › Settings › Signatures › +.
  3. Untick "Always match my default message font".
  4. Paste into the right-hand box.

Outlook

  1. Click Copy signature.
  2. Settings › Accounts › Signatures › New signature.
  3. Paste, then Save. If the layout breaks, use Copy HTML code with an HTML signature tool instead.
